Cardstock makes greeting cards. You tell an agent what the card is for, and
it writes the words and picks pictures from around the web. You get the
card's link, with the whole card sealed in it, and whoever opens it sees an
envelope that opens into a paper card, with the effect and music you chose.

You can change any card afterwards in the web app on your phone or computer,
and save it as a still, an MP4 or a GIF to send in a chat.

## What it does

- **Cards from a description:** an agent turns what you ask for into a card,
  with pictures, video and music from their web addresses. See
  [Making a card](/making-a-card) and [Where to find pictures](/pictures).
- **The card in its link:** the whole card is sealed into its link, so
  nothing is stored and the server never sees it. See
  [Links and privacy](/links-and-privacy).
- **A 3D paper card:** the envelope, the fold and the paper are drawn with
  three.js on WebGPU, falling back to WebGL.
- **The web app:** make and change cards, kept on the device you made them
  on, installed on a phone or computer. See [The web app](/web-app).
- **For agents:** the `cardstock` CLI with Code Mode and MCP, and a skill that
  tells an agent how to use them. See [CLI](/cli) and [Agents](/agents).

## Parts

| Part              | What it is                                                         |
| ----------------- | ------------------------------------------------------------------ |
| `packages/card`   | The card format, encryption, renderer, designs, effects and export |
| `packages/app`    | The web app, with the viewer and editor                            |
| `packages/server` | The Cloudflare Worker that serves the app and the picture fetcher  |
| `packages/cli`    | The `cardstock` CLI, with Code Mode and MCP for agents             |
| `docs`            | This site                                                          |
