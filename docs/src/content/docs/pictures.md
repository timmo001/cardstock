title: Where to find pictures

---

Cardstock doesn't search for pictures itself, and keeps no files. Find one
on a site below, copy the address of the picture itself (open it on its own
and copy that address, rather than the page it's on), then add it: **From a
link** in the [web app](/web-app), or `cardstock media add --url <address>`
from the [CLI](/cli). The card loads it from there each time it opens.

## What the licences ask

The Unsplash, Pexels and Pixabay licences and CC0 ask for nothing: use the
picture as you like. A CC BY or CC BY-SA licence asks you to say who made it,
so write that into the card's message, such as "Photo: Jane Doe, CC BY". Skip
anything marked NC (non-commercial) or ND (no changes) if you're unsure, and
anything without a licence at all.

## Agents

An agent with web access can do the same: search one of these sites, find
the file's own address, and add it with `--url`. The [skill](/agents) tells
it to.
